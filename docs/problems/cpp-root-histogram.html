Llena un histograma ROOT

Convierte un vector de mediciones en el primer objeto ROOT que usarás todo el tiempo: un TH1D.

TH1DFillbinningunderflow/overflow

Problema

Implementa TH1D* build_histogram(const std::vector<double>& values). Devuelve un TH1D reservado en el heap, llamado h_pt, con 10 bins que cubren [0, 100], llenando cada valor exactamente una vez.

Implementabuild_histogram(…)

Ejemplo

Entrada{10, 20, 30}
SalidaTH1D con 3 entradas y media 20

Cada valor de entrada aporta una llamada a Fill.

Requisitos

  • Usa exactamente 10 bins de 0 a 100.
  • Nombra el histograma h_pt.
  • Llena cada valor de entrada exactamente una vez.
  • Devuelve un puntero creado con new TH1D(...).

Qué practicas

Crear un histograma de ROOT con un binning explícito y llenarlo una vez por cada valor de entrada.

Referencias

  • TH1 — ROOT reference
  • std::vector — cppreference
