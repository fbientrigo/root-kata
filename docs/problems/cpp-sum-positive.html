Suma valores positivos

Calienta con el patrón bucle + condición + acumulador que se usa en todo análisis de datos.

std::vectorbucle range-forifacumulador

Problema

Implementa double sum_positive(const std::vector<double>& values). Devuelve la suma de los valores estrictamente mayores que cero.

Implementasum_positive(…)

Ejemplo

Entrada{-2, 3, 0, 5}
Salida8

Solo 3 y 5 son estrictamente positivos.

Requisitos

  • Devuelve 0 para un vector vacío.
  • Ignora los valores cero y negativos.
  • No modifiques el vector de entrada.

Qué practicas

Recorrer un vector, decidir por cada valor y acumular un resultado numérico.

Referencias

  • std::vector — cppreference
  • Range-based for loop — cppreference
