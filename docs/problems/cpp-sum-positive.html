Sum positive values

Warm up with the loop + condition + accumulator pattern used throughout data analysis.

std::vectorrange-forifaccumulator

Problem

Implement double sum_positive(const std::vector<double>& values). Return the sum of values strictly greater than zero.

Implementsum_positive(…)

Example

Input{-2, 3, 0, 5}
Output8

Only 3 and 5 are strictly positive.

Requirements

  • Return 0 for an empty vector.
  • Ignore zero and negative values.
  • Do not modify the input vector.

What this practices

Traverse a vector, make a decision for each value, and accumulate a numeric result.
