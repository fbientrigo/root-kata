Recupera un pico con un ajuste gaussiano

Ajusta un pico determinista y reporta el estado, la posición y el ancho ajustados en vez de juzgar la curva a ojo.

TH1DTF1FitGaussianfit statusparameters

Problema

Implementa PeakFit fit_peak(TH1D& hist). Ajusta el histograma con pico usando una TF1 gaussiana en x dentro de [2,8] y devuelve el estado del ajuste, la media ajustada y un sigma positivo.

Implementafit_peak(…)

Ejemplo

Entradadeterministic peak centered near 5 with width near 0.8
Salidastatus=0, mean≈5, sigma≈0.8

El resultado numérico del ajuste es la evidencia; una curva visualmente plausible no basta.

Requisitos

  • Usa una TF1 gaussiana en el rango de ajuste [2,8].
  • Ajusta el histograma entregado en vez de reemplazar su contenido.
  • Devuelve el estado del ajuste para que un fallo sea observable.
  • Devuelve la media gaussiana ajustada y un sigma ajustado positivo.

Qué practicas

Usar un modelo ajustado como resultado numérico: comprobar el estado e interpretar posición y ancho desde los parámetros.

Referencias

  • TH1 — ROOT reference
  • ROOT fitting manual
