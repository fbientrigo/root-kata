Lee un valor de un arreglo

Usa [] una sola vez: lee un valor de un arreglo fijo de C++.

arreglo C++índice []return

Problema

Implementa int second_value(). El arreglo ya está creado; devuelve su segundo elemento.

Implementasecond_value(…)

Ejemplo

Entrada{10, 20, 30}
Salida20

Los índices de un arreglo en C++ comienzan en 0, así que el segundo elemento es values[1].

Requisitos

  • Usa el arreglo que ya aparece en el starter.
  • Devuelve el segundo elemento.
  • No cambies los valores del arreglo.

Qué practicas

Leer un valor de un arreglo de tamaño fijo usando un índice.

Referencias

  • Built-in arrays — cppreference
