Inspecciona un histograma ROOT

Lee lo que realmente contiene un TH1D: entradas totales, un bin elegido y estadísticas resumen.

TH1DGetEntriesGetBinContentGetMeanGetStdDev

Problema

Implementa HistogramInspection inspect_histogram(const TH1D& hist, int bin). Lee el histograma sin modificarlo y devuelve sus entradas totales, el contenido del bin ROOT solicitado, la media y la desviación estándar.

Implementainspect_histogram(…)

Ejemplo

Entrada5 filled observations; requested bin contains 2
Salidaentries = 5, bin_content = 2

Entries cuenta observaciones; el contenido de un bin cuenta solo las observaciones representadas por ese bin.

Requisitos

  • No llenes, reinicies ni modifiques el histograma.
  • Devuelve GetEntries() como entries.
  • Devuelve GetBinContent(bin) para el número de bin ROOT solicitado.
  • Devuelve la media y la desviación estándar de las estadísticas del histograma.

Qué practicas

Distinguir las entradas totales de un histograma del contenido de bins individuales e inspeccionar directamente sus estadísticas numéricas.
