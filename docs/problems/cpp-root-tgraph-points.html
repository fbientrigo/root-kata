Conserva mediciones pareadas con TGraph

Representa pares medidos x-y sin convertir sus coordenadas x en números de punto implícitos.

TGraphpaired dataGetPointcoordinates

Problema

Implementa TGraph* build_graph(const std::vector<double>& x, const std::vector<double>& y). Los dos vectores tienen igual longitud. Conserva cada par ordenado y su orden de entrada.

Implementabuild_graph(…)

Ejemplo

Entradax={0,1.5,4}, y={2,3.5,3}
Salida(0,2), (1.5,3.5), (4,3)

Un gráfico almacena coordenadas pareadas; el índice del punto no reemplaza a x.

Requisitos

  • Devuelve un TGraph con exactamente un punto por cada par de entrada.
  • Usa los valores x entregados como coordenadas x.
  • Usa los valores y entregados como coordenadas y.
  • Conserva el orden de las mediciones.

Qué practicas

Elegir TGraph para mediciones pareadas y conservar la correspondencia x-y real.
