Count values above a cut

Practice the core analysis operation: apply a threshold and count what survives.

std::vectorfunction argumentsstrict comparisonselection

Problem

Implement int count_above(const std::vector<double>& values, double threshold). Count values strictly greater than threshold.

Implementcount_above(…)

Example

Inputvalues = {20, 35, 50, 35}, threshold = 35
Output1

Only 50 is strictly greater than 35.

Requirements

  • Use a strict > comparison: a value equal to the threshold does not pass.
  • Return 0 for an empty vector.
  • Do not modify the input vector.

What this practices

Translate a numerical selection into a precise C++ condition and count the values that survive it.
