Cuenta valores sobre un corte

Practica la operación central del análisis: aplica un umbral y cuenta lo que sobrevive.

std::vectorargumentos de funcióncomparación estrictaselección

Problema

Implementa int count_above(const std::vector<double>& values, double threshold). Cuenta los valores estrictamente mayores que el umbral.

Implementacount_above(…)

Ejemplo

Entradavalues = {20, 35, 50, 35}, threshold = 35
Salida1

Solo 50 es estrictamente mayor que 35.

Requisitos

  • Usa una comparación estricta con >: un valor igual al umbral no pasa.
  • Devuelve 0 para un vector vacío.
  • No modifiques el vector de entrada.

Qué practicas

Traducir una selección numérica a una condición C++ precisa y contar los valores que la superan.

Referencias

  • Range-based for loop — cppreference
  • std::vector — cppreference
