Keep calibration values visible

Diagnose a histogram range that silently sends a boundary measurement to overflow.

TH1DbinningunderflowoverflowGetBinContent

Problem

Repair TH1D* build_calibration_histogram(const std::vector<double>& values). Calibration measurements span 0 through 100 inclusive and must stay in visible 10-unit bins rather than disappearing into underflow or overflow.

Implementbuild_calibration_histogram(…)

Example

Input{0, 10, ..., 100}
Output11 visible entries, overflow = 0

In ROOT the upper histogram edge belongs to overflow, so a [0,100) visible range does not contain x = 100.

Requirements

  • Name the histogram h_calibration.
  • Keep 10-unit-wide visible bins.
  • Make the intended 0 through 100 calibration range visible, including the value 100.
  • Fill every input value exactly once.

What this practices

Use underflow and overflow as evidence that a histogram range does not represent the intended sample.
