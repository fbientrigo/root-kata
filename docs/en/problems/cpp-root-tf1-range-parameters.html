Diagnose a plausible but wrong TF1

Repair a decay model whose formula is valid but whose parameter mapping and domain make its predictions misleading.

TF1model rangeparametersdiagnosisexponential

Problem

Repair TF1* build_decay_model(double amplitude, double tau). It must represent A*exp(-x/tau) on the analysis domain [0,10], with amplitude in parameter 0 and tau in parameter 1.

Implementbuild_decay_model(…)

Example

Inputamplitude=12, tau=2
Outputf(0)=12, f(4)=12*exp(-2)

The same formula gives the wrong interpretation if the parameters are swapped or the intended model range is misconfigured.

Requirements

  • Name the function decay_model.
  • Use [0]*exp(-x/[1]) for A*exp(-x/tau).
  • Use the intended model domain [0,10].
  • Map amplitude to parameter 0 and tau to parameter 1.

What this practices

Diagnose model configuration separately from formula syntax by checking parameter meaning, range, and numerical predictions.
