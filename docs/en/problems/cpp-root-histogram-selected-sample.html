Turn a selection into a distribution

Combine a strict numerical cut with histogram filling, then distinguish selected entries from visible entries.

selectionTH1Dstrict cutoverflowintegration

Problem

Implement TH1D* build_selected_histogram(const std::vector<double>& values, double threshold). Keep only values strictly greater than threshold and fill them into h_selected with 5 bins covering [0,150].

Implementbuild_selected_histogram(…)

Example

Inputvalues={20,50,50.1,80,120}, threshold=50
Output3 entries

The boundary value 50 does not survive a strict > 50 cut.

Requirements

  • Create h_selected with 5 bins covering [0,150].
  • Apply the strict condition value > threshold.
  • Fill each surviving value exactly once and reject every non-survivor.
  • Do not discard selected values merely because they fall in underflow or overflow.

What this practices

Compose a numerical selection and a histogram while keeping selection semantics separate from histogram range semantics.
