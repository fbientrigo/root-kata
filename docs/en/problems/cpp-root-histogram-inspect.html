Inspect a ROOT histogram

Read what a TH1D actually contains: total entries, a chosen bin, and summary statistics.

TH1DGetEntriesGetBinContentGetMeanGetStdDev

Problem

Implement HistogramInspection inspect_histogram(const TH1D& hist, int bin). Read the histogram without modifying it and return its total entries, the content of the requested ROOT bin, mean, and standard deviation.

Implementinspect_histogram(…)

Example

Input5 filled observations; requested bin contains 2
Outputentries = 5, bin_content = 2

Entries count observations; a bin content counts only observations represented by that bin.

Requirements

  • Do not fill, reset, or otherwise modify the histogram.
  • Return GetEntries() as entries.
  • Return GetBinContent(bin) for the requested ROOT bin number.
  • Return the histogram mean and standard deviation from ROOT's histogram statistics.

What this practices

Distinguish total histogram entries from individual bin contents and inspect numerical summary statistics directly.
