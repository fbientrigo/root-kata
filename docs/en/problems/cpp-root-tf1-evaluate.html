Turn a formula into a ROOT model

Build a parameterized TF1 and observe how changing one parameter changes the model.

TF1parametersEvalSetParametermodel

Problem

Implement TF1* build_linear_model(double intercept, double slope). Build f(x) = intercept + slope*x on the domain [0,10], store intercept in parameter 0 and slope in parameter 1, and name the function calibration_model.

Implementbuild_linear_model(…)

Example

Inputintercept=2, slope=3
Outputf(0)=2, f(2)=8

The parameters carry the model state; changing the slope changes later evaluations.

Requirements

  • Name the TF1 calibration_model.
  • Use the model [0] + [1]*x on the domain [0,10].
  • Set parameter 0 to the intercept argument.
  • Set parameter 1 to the slope argument.

What this practices

Connect a mathematical model, its parameter values, and the numerical predictions produced by TF1.
