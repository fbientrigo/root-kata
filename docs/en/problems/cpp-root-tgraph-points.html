Preserve paired measurements with TGraph

Represent measured x-y pairs without turning their x coordinates into implicit bin numbers.

TGraphpaired dataGetPointcoordinates

Problem

Implement TGraph* build_graph(const std::vector<double>& x, const std::vector<double>& y). The two vectors have equal length. Preserve each ordered pair and its input order.

Implementbuild_graph(…)

Example

Inputx={0,1.5,4}, y={2,3.5,3}
Output(0,2), (1.5,3.5), (4,3)

A graph stores paired coordinates; the point index is not a replacement for x.

Requirements

  • Return a TGraph containing exactly one point per input pair.
  • Use the supplied x values as x coordinates.
  • Use the supplied y values as y coordinates.
  • Preserve the order of the measurements.

What this practices

Choose TGraph for paired measurements and preserve the actual x-y correspondence.
