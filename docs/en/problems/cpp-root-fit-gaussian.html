Recover a peak with a Gaussian fit

Fit a deterministic peak and report the fit status, fitted location, and fitted width instead of judging the curve by eye.

TH1DTF1FitGaussianfit statusparameters

Problem

Implement PeakFit fit_peak(TH1D& hist). Fit the supplied peaked histogram with a Gaussian TF1 over x in [2,8], then return the fit status, fitted mean, and positive sigma.

Implementfit_peak(…)

Example

Inputdeterministic peak centered near 5 with width near 0.8
Outputstatus=0, mean≈5, sigma≈0.8

The numerical fit result is the evidence; a visually plausible curve is not enough.

Requirements

  • Use a Gaussian TF1 over the fit range [2,8].
  • Fit the supplied histogram rather than replacing its contents.
  • Return the fit status so failure is observable.
  • Return the fitted Gaussian mean and a positive fitted sigma.

What this practices

Use a fitted model as a numerical result: check status and interpret location and width from fitted parameters.
