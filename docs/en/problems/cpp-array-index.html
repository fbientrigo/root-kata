Read from an array

Use [] once: read one value from a fixed C++ array.

C++ arrayindex []return

Problem

Implement int second_value(). The array is already created for you; return its second element.

Implementsecond_value(…)

Example

Input{10, 20, 30}
Output20

C++ array indices start at 0, so the second element is values[1].

Requirements

  • Use the array already present in the starter.
  • Return the second element.
  • Do not change the values in the array.

What this practices

Read a value from a fixed-size C++ array using an index.
