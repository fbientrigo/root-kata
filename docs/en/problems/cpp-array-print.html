Print an array

Print the values already stored in a tiny C++ array.

C++ arraystd::coutiteration

Problem

Implement void print_values(). Print the three values in the array in order. Spaces or line breaks between values are both accepted.

Implementprint_values(…)

Example

Input{4, 8, 15}
Output4 8 15

Whitespace formatting is flexible; the order and values are what matter.

Requirements

  • Print 4, 8 and 15 in that order.
  • Use the values array already present in the starter.
  • Do not print extra numbers.

What this practices

Connect stored values in an array with visible program output.
