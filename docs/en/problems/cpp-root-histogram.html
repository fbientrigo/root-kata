Fill a ROOT histogram

Turn a vector of measurements into the first ROOT object you will use constantly: a TH1D.

TH1DFillbinningunderflow/overflow

Problem

Implement TH1D* build_histogram(const std::vector<double>& values). Return a heap-allocated TH1D named h_pt with 10 bins covering [0, 100], with every value filled exactly once.

Implementbuild_histogram(…)

Example

Input{10, 20, 30}
OutputTH1D with 3 entries and mean 20

Each input value contributes one Fill call.

Requirements

  • Use exactly 10 bins from 0 to 100.
  • Name the histogram h_pt.
  • Fill each input value exactly once.
  • Return a pointer created with new TH1D(...).

What this practices

Create a ROOT histogram with an explicit binning and fill it once for every input value.
